# Конституция Михаила

Один большой документ на язык. Не набор отдельных статей, а цельный протокол решений в стиле ToS/Guidelines.

## Файлы

```
src/data/constitution/
  constitution.ru.md   # основной текст
  constitution.en.md   # английская версия
  README.md            # эта инструкция
```

Если файла на нужном языке нет, сайт покажет русскую версию и отметит, что перевод отсутствует. Корейская версия добавляется позже как `constitution.ko.md`.

## Структура markdown

```md
---
title: Конституция Михаила
subtitle: Протокол решений, а не истина
adopted: 2026-03-01
place: Сеул, Корея
edition: 2.0
motto: Не истина. Протокол решений.
---

Текст преамбулы. Всё, что стоит до первой части, показывается как преамбула.

## I. Основание

Короткое вступление к части.

### 1.1. Зачем этот документ

Текст раздела.

##### Подпункт

Текст подпункта.
```

## Правила

- `## I. Название`: часть документа. Нумерация римская.
- `### 1.1. Название`: раздел внутри части. Нумерация арабская.
- `##### 1.1.1. Название`: подпункт внутри раздела. Используй пять решёток, чтобы не ломать оглавление.
- `####` лучше не использовать: оно останется внутри раздела, но визуально совпадёт с заголовком раздела.
- Таблицы, списки, цитаты и `**жирный**` поддерживаются.
- ID разделов строятся из номера: `1.1` → `section-1-1`. Менять номера без причины не стоит: прогресс чтения хранится по ID.
- Преамбула: всё до первого `##`.
- История версий и подпись: обычные разделы в конце документа.

## Как добавить часть

1. Добавь `## XII. Название` в конец или в нужное место.
2. Добавь разделы `### 12.1. ...`, `### 12.2. ...`.
3. Обнови `edition` в frontmatter, если меняется версия.
4. Проверь `pnpm typecheck` и `pnpm build`.

## Как добавить раздел

1. Добавь `### 5.5. Название` внутри нужной части.
2. Напиши текст, списки или таблицу.
3. Не меняй номера соседних разделов без необходимости.

## Как добавить язык

1. Скопируй `constitution.ru.md` в `constitution.ko.md`.
2. Переведи frontmatter и текст.
3. Сохрани те же номера частей и разделов: по ним работает прогресс чтения.

## Важно

- Не удаляй `---` в начале и конце frontmatter.
- Не используй `##` и `###` внутри текста раздела, если не хочешь создать новую часть или раздел.
- Для подпунктов используй `#####`.
- После правок проверь `pnpm typecheck` и `pnpm build`.
